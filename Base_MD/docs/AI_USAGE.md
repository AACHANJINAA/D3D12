# AI Usage

## 참조 원칙

최신 사용자 직접 요청과 관련 코드가 우선입니다.
PLAY_REQUEST는 보조 자료이며 이미 요청한 작업을 재승인하는 절차가 아닙니다.
매번 모든 문서를 읽지 않고 필요한 문서 / 섹션만 확인합니다.
Base_MD 전체 고도화처럼 전체가 대상이면 전체 일관성을 확인합니다.

| 작업 | 우선 참조 |
| --- | --- |
| 구현 | 관련 코드, ARCHITECTURE, 해당 마일스톤 |
| 계획 / 상태 | Implementation Plan, PLANS |
| 버그 / 검증 | 관련 코드, Verify |
| 렌더 경로 변경 | ARCHITECTURE, DECISIONS, Verify |
| 목표 변경 | Game_GDD, DECISIONS |

## 실행과 갱신

사용자 변경을 유지하고 요청 범위에 필요한 수정만 수행합니다.
설정, 도구 설치, 빌드 성공, 화면 성공을 구분합니다.
GPU 기술 판단은 Microsoft 공식 문서 / 예제로 확인합니다.
상태는 PLANS, 구조는 ARCHITECTURE, 확정 선택은 DECISIONS에 반영합니다.
Git이 있을 때 이력을 사용하며 커밋과 초기화는 별도 요청 없이 수행하지 않습니다.

## 확인 조건

상충하는 요구, 결과를 바꾸는 근거 없는 선택, 명시한 제한 초과,
파괴적 작업이 있을 때 확인합니다.
이미 요청한 문서 고도화, 관련 파일 생성과 필요한 검증에는 반복 확인을 요구하지 않습니다.
