# Workflow

## 작업 절차

1. 최신 요청의 범위와 완료 기준을 확인합니다.
2. 관련 문서와 실제 코드 / 프로젝트 설정을 읽습니다.
3. 확정 선택과 제안 기본값을 구분하고 수정 방향을 알립니다.
4. 필요한 문서 또는 코드를 수정합니다.
5. 문서 링크, 빌드, 화면과 GPU 수명을 변경 범위에 맞게 검증합니다.
6. 변경한 상태와 구조를 기준 문서에 반영합니다.
7. 결과와 미검증 사항을 보고합니다.

직접 요청은 오래된 요청서보다 우선하며 요청서 작성은 선택 사항입니다.
이미 요청한 파일 생성이나 여러 문서 수정에 반복 확인을 요구하지 않습니다.
상충하는 요구나 범위 밖의 중요한 변경만 확인합니다.
